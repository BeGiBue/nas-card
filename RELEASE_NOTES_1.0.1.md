# NAS Card 1.0.1

Vorbereitung der NAS Card für die Veröffentlichung in HACS Defaults.

## Änderungen

- Lizenz auf GNU Affero General Public License v3.0 only (AGPL-3.0-only) umgestellt.
- Versionsangaben im Repository auf 1.0.1 vereinheitlicht.
- HACS-Validierung für Pushes auf `main`, Pull Requests und manuelle Ausführung aktiviert.
- README und Release-Unterlagen für die HACS-Veröffentlichung aktualisiert.

## Installation

Die NAS Card kann über HACS als Dashboard-Plugin installiert werden. Die Kartenkonfiguration bleibt unverändert:

```yaml
type: custom:nas-card
```
